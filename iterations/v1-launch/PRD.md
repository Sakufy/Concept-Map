# 概念地图软件 · PRD · v1-launch

> 文件位置：`iterations/v1-launch/PRD.md`
> 配合项目根 BRIEF.md（见 `概念地图软件开发方案.md`）阅读。这份 PRD 描述 v1-launch 要做的功能。

## 1. 项目背景

概念地图软件：对标 Lynkage 的概念图绘制工具，让用户在无限画布上摆放概念节点、用带连词标签的连线表达概念关系。电脑 + 手机双端可用。

参见：[概念地图软件开发方案.md](../../概念地图软件开发方案.md)

## 2. 本次目标（v1-launch）

上线后用户能在浏览器中：
- 创建一张概念图（无限画布上添加/拖拽/编辑/删除概念节点）
- 用带连词标签的连线连接概念（`概念 —连词→ 概念`）
- 刷新不丢数据（本地持久化），可导出/导入 JSON
- 手机浏览器可平移/缩放/点选（双端可用）

## 3. 用户与关键场景

### 场景 1：课堂记录概念图
- **用户**：学生/教师，用 Lynkage 画概念图，希望在手机和电脑间切换
- **旅程**：电脑打开网页 → 双击空白新建概念 → 输入"光合作用" → 拖出连线到"叶绿体" → 点击连线输入连词"发生在" → 刷新页面数据还在
- **结果**：能随时记录和回顾知识结构

### 场景 2：移动端碎片时间整理
- **用户**：通勤中的用户，手机上快速整理思路
- **旅程**：手机浏览器打开 → 单指平移画布 → 双指缩放 → 点击节点编辑文字 → 双指捏合缩小看全貌
- **结果**：在手机上完成一次完整的概念图编辑

### 场景 3：备份与迁移
- **用户**：习惯本地掌控数据的用户
- **旅程**：导出 JSON → 换设备/清理缓存 → 导入 JSON 恢复原图
- **结果**：数据可自主备份与迁移

## 4. 功能模块（非网站项目的"页面结构"）

| 模块 | 用途 | 验收要点 |
|------|------|---------|
| 无限画布 | 平移/缩放/框选 | 双指缩放、平滑拖拽 |
| 概念节点 | 添加/拖拽/编辑/删除 | 双击编辑文字；拖拽移动；可删除 |
| 连线 | 节点间连接 | 从节点拖出到另一节点；可删除 |
| 连词标签 | 连线上的语义文本 | 点击连线可输入连词 |
| 本地持久化 | IndexedDB 自动保存 | 刷新不丢；导出/导入 JSON |
| 移动端适配 | 触摸手势 | 单指平移/双指缩放/点选编辑 |

## 5. 范围

**v1 会做**：上述 6 个功能模块；基础节点样式（颜色可区分）；撤销/重做。

**v1 明确不做**：
- 云端账号/同步（v2）
- 嵌入式子节点（v2）
- 资源挂载（附件/图片/链接）
- 分享链接
- 实时协作
- 自动布局

## 6. 目标衡量

**主指标**：完成 v1 的 6 个功能模块验收清单全部通过（见 `.plan/phases/`）。

**过程指标**：
- 电脑端：画布拖拽/缩放流畅（无卡顿）
- 移动端：真机验证手势可用
- 持久化：刷新/重启浏览器数据不丢

## 7. 风险与待解决问题

**已知常见项：**
- React Flow 移动端触摸手势与编辑冲突（双击 vs 缩放）
- IndexedDB 在 Safari 隐私模式下的可用性
- 连词标签的编辑交互（点击连线 vs 拖拽连线）
